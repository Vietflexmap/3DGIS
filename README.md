# Vietflex 3D Tourism · Bến Tre

Website du lịch 3D/VR 360° dành cho 11 điểm đến Bến Tre, triển khai trực tiếp bằng GitHub Pages.

## Chức năng
- Giao diện 3D-inspired responsive cho desktop/mobile
- 11 điểm đến với tìm kiếm và bộ lọc
- Trình xem VR toàn màn hình bằng URL tour gốc
- Việt / Anh
- PWA shell + Service Worker
- Fallback Mở tour gốc nếu nền tảng bên thứ ba chặn iframe

## GitHub Pages
Khuyến nghị: Deploy from a branch → main → / (root).

Trang dự kiến: https://vietflexmap.github.io/3DGIS/

## Lưu ý
Website không sao chép hay đóng gói nội dung VR của bên thứ ba. Tour VR và ảnh nguồn vẫn nằm trên máy chủ của nhà cung cấp tương ứng và cần Internet để hoạt động.
